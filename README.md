Спрощений калькулятор, що обробляє натискання клавіш над цілими числами.
Клавіші: `0`–`9`, `+`, `-`, `*`, `/`, `=`. Допустимий порядок: цифри, оператор,
цифри, `=`. Ділення — цілочисельне з округленням вниз.

Ділення на нуль спричиняє `ZeroDivisionError`; невідома клавіша або неприпустима
послідовність (`=` без оператора, другий оператор) — `ValueError`.

## Встановлення

```bash
pip install -r requirements.txt
```

## Тести

```bash
pytest
```

## Приклад запуску

Вхідний файл `input.txt` (назви клавіш через один пробіл):

```
1 2 3 + 4 5 6 =
```

Запуск:

```bash
python -m src.calculator input.txt output.txt
```

Вихідний файл `output.txt` (число на екрані після останньої клавіші):

```
579
```
